# 1.2.1

Fixed the API compatibility error reported by Obsidian's automated review. The plugin now checks the running Obsidian version before accessing Secret storage. Obsidian 1.5.7 remains supported: versions before 1.11.4 keep browser credentials in memory, and newer versions can restore them from Secret storage.

Updated browser crypto and timers, cancellation errors, and repository response typing to address source review warnings. Production builds now run the official Obsidian API compatibility checker before bundling.

Obsidian 자동 심사에서 지적된 API 호환성 오류를 수정했습니다. 최소 지원 버전은 1.5.7이며, 1.11.4 미만에서는 로그인 정보를 실행 중 메모리에만 보관합니다.

Validation: source lint, TypeScript checks, 112 plugin tests, 52 Cloudflare tests, and 11 browser tests passed. The compatibility tests cover Obsidian 1.5.7, 1.11.3, 1.11.4, and 1.13.1 with mocked API versions; they do not run those Obsidian binaries. Browser tests use the production bundle and block external requests.
