# 1.2.0 — Connect with GitHub

Connect your image repository through GitHub's browser login, without manually creating and copying a PAT. OAuth tokens are kept out of the plugin's `data.json`.

> 이제 PAT를 직접 발급해 붙여넣을 필요 없이, 브라우저에서 GitHub에 로그인하면 이미지 업로드를 연결할 수 있습니다. OAuth 토큰은 플러그인의 평문 설정 파일인 `data.json`에 저장하지 않습니다. Obsidian 1.11.4 이상에서는 Secret storage, 이전 버전에서는 실행 중 메모리에 보관합니다.

- New installations use the hosted authentication relay. Install the GitHub App on your dedicated public image repository, connect, and choose the repository in the plugin settings.
- Browser authorization uses PKCE S256 and single-use login transactions. Expiring access tokens renew automatically, with concurrent uploads sharing one refresh request.
- Images go directly from Obsidian to GitHub. The relay handles authentication and keeps the App client secret on the server; images never pass through it.
- Existing PAT settings, custom relay addresses, and explicitly empty relay addresses are preserved. PAT setup remains available in **Advanced settings**.

On **Obsidian 1.11.4 or later**, OAuth credentials use Obsidian Secret storage, which other plugins can access. On older supported versions, they stay in memory and require reconnecting after restarting or reloading the plugin. The minimum supported Obsidian version remains **1.5.7**.

Switching to browser login does not remove a saved PAT. That PAT remains unencrypted in plugin `data.json`; if you no longer use it, clear it in **Advanced settings** and revoke it on GitHub. **Disconnect** clears the local browser credentials and attempts remote token revocation. A network failure can prevent confirmation, so GitHub's authorization settings remain available for manual revocation.

Use a dedicated **public** repository and grant the App **Contents: read and write** only there. Every uploaded image is public, and this permission can modify other files in that repository too. The hosted relay runs on Cloudflare's Free plans; their limits can temporarily interrupt login or token renewal.

Validation: 112 plugin and API tests, 48 Cloudflare tests, and 11 browser tests against the production bundle passed. Automated GitHub requests are mocked. A real App login, desktop callback, repository selection, and sample upload were also checked in Obsidian 1.12.7 on macOS. Mobile callback return still needs live validation.

See the [README](https://github.com/HyoYoonNam/image-paste-on-github#readme) for setup, credential storage, and failure handling.
