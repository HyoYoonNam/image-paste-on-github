# 1.2.2

Settings now appear individually in Obsidian's settings search on 1.13.0 and later, including the Advanced settings page. Older supported versions render the same definitions with the existing settings API. The minimum Obsidian version remains 1.5.7. Authentication changes refresh the appropriate settings view without calling the deprecated display API.

Release assets are now built and tested in GitHub Actions, signed with GitHub artifact attestations, and verified against the release tag and source commit before publication. The README directs users to the plugin's GitHub App installation button instead of a link that the review scanner misidentified as another repository.

설정 검색 지원과 배포 파일의 빌드 출처 증명을 추가했습니다. 구버전 설정 화면, 저장된 PAT, 로그인 정보 보관 방식은 유지합니다.

Validation covers plugin tests, the local Cloudflare authentication runtime, and production-bundle browser tests for both legacy and declarative settings. The browser tests use mocked Obsidian APIs and block external requests; they check login, repository selection, advanced-setting search metadata, masked PAT fields, updates, and persistence.
